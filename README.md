# NIRUDRUMS

An early prototype of a drum machine for Linux, built in Rust.

- Version: 0.0.1
- Standalone application and VST3 instrument
- MERCY-80 kit with 12 instruments and three velocity layers
- Step sequencer, mixer, effects and WAV export
- Linux x86_64 only; tested build
- Under active development; expect unfinished features and bugs

See `CHANGELOG.md` and `KNOWN_LIMITATIONS.md` for the current state.

NIRUDRUMS 0.0.1 — concept, design, and creative direction by Nicklas Rudolfsson.
